政府采购框架协议采购方式管理暂行办法政策解读

发布日期：2025-10-19 来源：中华人民共和国财政部
代理商获取授权 立即入驻框架协议

2022年1月14日，财政部发布了《政府采购框架协议采购方式管理暂行办法》（财政部令第110号），该办法自2022年3月1日起正式施行。这是我国政府采购领域首次针对框架协议采购方式制定的专门管理办法，为规范多频次、小额度采购活动提供了明确的法律依据。

一、框架协议采购方式概述

框架协议采购是指集中采购机构或者主管预算单位对技术、服务等标准明确、统一，需要多次重复采购的货物和服务，通过公开征集程序，确定第一阶段入围供应商并订立框架协议，采购人或者服务对象按照框架协议约定规则，在入围供应商范围内确定第二阶段成交供应商并订立采购合同的采购方式。

政策要点：框架协议采购主要适用于多频次、小额度采购，分为封闭式和开放式两种形式，其中封闭式框架协议采购是主要形式。

二、框架协议采购的适用情形

根据办法规定，符合下列情形之一的，可以采用框架协议采购方式：

1. 集中采购目录内的小额零星采购

集中采购目录以内品目，以及与之配套的必要耗材、配件等，属于小额零星采购的。

2. 部门专用服务的零星采购

集中采购目录以外，采购限额标准以上，本部门、本系统行政管理所需的法律、评估、会计、审计等鉴证咨询服务，属于小额零星采购的。

3. 政府购买服务的多供应商选择

集中采购目录以外，采购限额标准以上，为本部门、本系统以外的服务对象提供服务的政府购买服务项目，需要确定2家以上供应商由服务对象自主选择的。

4. 其他规定情形

国务院财政部门规定的其他情形。

适用提示：主管预算单位能够归集需求形成单一项目进行采购，通过签订时间、地点、数量不确定的采购合同满足需求的，不得采用框架协议采购方式。

三、框架协议采购的两种形式

1. 封闭式框架协议采购

封闭式框架协议采购是框架协议采购的主要形式，通过公开竞争订立框架协议后，除经过框架协议约定的补充征集程序外，不得增加协议供应商。

主要特点：

  • 公开征集程序按照政府采购公开招标的规定执行
  • 确定入围供应商时采用价格优先法或质量优先法
  • 有明确的淘汰比例要求（一般不低于20%）
  • 框架协议有效期内供应商数量基本固定

2. 开放式框架协议采购

开放式框架协议采购是指明确采购需求和付费标准等框架协议条件，愿意接受协议条件的供应商可以随时申请加入的框架协议采购。

适用情形：

  • 因执行政府采购政策不宜淘汰供应商的
  • 受基础设施、行政许可、知识产权等限制，供应商数量在3家以下且不宜淘汰供应商的
  • 能够确定统一付费标准，因地域等服务便利性要求，需要接纳所有愿意接受协议条件的供应商

四、框架协议采购流程详解

第一阶段：框架协议订立

  1. 确定采购需求：征集人应当确定框架协议采购需求，并在有效期内不得变动
  2. 发布征集公告：通过省级以上财政部门指定媒体发布征集公告
  3. 供应商响应：供应商按照征集文件要求编制和提交响应文件
  4. 评审确定入围：采用价格优先法或质量优先法确定入围供应商
  5. 签订框架协议：征集人与入围供应商签订框架协议

第二阶段：合同授予

采购人或者服务对象按照框架协议约定的规则，在入围供应商范围内确定成交供应商：

确定方式 适用情形 特点
直接选定 主要方式，适用于大多数项目 依据入围产品价格、质量以及服务便利性、用户评价等因素直接选定
二次竞价 价格优先法的采购项目 以协议价格为最高限价，选择符合需求的供应商参与二次竞价
顺序轮候 服务项目 根据轮候顺序规则，依次授予采购合同

五、厂商注意事项

对于生产厂商而言，参与框架协议采购需注意以下要点：

  1. 入围供应商资格：货物项目框架协议的入围供应商应当为入围产品生产厂家或者生产厂家唯一授权供应商
  2. 代理商管理重要：入围供应商可以委托一家或者多家代理商，按照框架协议约定接受采购人合同授予
  3. 产品要求：响应的货物原则上应当是市场上已有销售的规格型号，不得是专供政府采购的产品
  4. 耗材配套：对耗材使用量大的仪器设备，应当同时对3年以上约定期限内的专用耗材进行报价
  5. 产品升级：在质量不降低、价格不提高的前提下，可以对入围产品进行升级换代

厂商授权关键点关键：厂商对代理商的授权在一年内只有一次机会，请务必慎重选择代理商并确保授权文件的完整性和准确性。

六、代理商注意事项获取授权是关键

对于代理商而言，参与框架协议采购需特别注意以下要点：

  1. 获取厂商授权关键：必须获得入围产品生产厂家的唯一授权，且厂商一年内只能进行一次授权
  2. 授权文件准备：确保授权文件符合征集文件要求，包括授权书、厂商资质证明等
  3. 授权时效性：注意授权有效期，确保在框架协议有效期内授权持续有效
  4. 代理关系维护：与厂商保持良好的合作关系，确保货源稳定和价格优势
  5. 区域限制注意：注意厂商授权是否有区域限制，避免跨区域经营风险

代理商关键提醒重要：由于厂商一年内只能进行一次授权，代理商应尽早与意向厂商沟通，争取获得授权机会，错过将需要等待下一年度。

七、入围注意事项入围是关键第一步

供应商参与框架协议采购应重点关注以下事项：

  1. 响应文件编制：严格按照征集文件要求编制响应文件，对响应文件的真实性和合法性承担法律责任
  2. 报价策略：响应报价不得超过最高限制单价，有量价关系折扣的应当明确
  3. 资格审查：确保符合供应商资格条件，提供真实有效的资格材料
  4. 履约责任：入围后应当认真履行框架协议义务，避免被清退的风险
  5. 退出机制：封闭式框架协议入围供应商无正当理由不得主动退出；开放式框架协议供应商可以随时申请退出

风险提示：供应商如有恶意串通、提供虚假材料、无正当理由拒不接受合同授予等情形，将被取消入围资格，且不得参加同一封闭式框架协议补充征集。

八、框架协议期限与补充征集

框架协议期限

  • 货物项目框架协议有效期一般不超过1年
  • 服务项目框架协议有效期一般不超过2年

补充征集规则

除剩余入围供应商不足入围供应商总数70%且影响框架协议执行的情形外，框架协议有效期内不得补充征集供应商。补充征集的条件、程序、评审方法和淘汰比例应当与初次征集相同。

九、对供应商的影响与建议

框架协议采购方式的正式确立，对供应商参与政府采购活动将产生深远影响：

  1. 把握入围机会：框架协议采购已成为小额零星采购的主要方式，供应商应积极把握第一阶段入围机会
  2. 关注电子化采购：框架协议采购应当实行电子化采购，供应商需熟悉电子采购系统操作
  3. 重视用户评价：用户反馈和评价情况将作为第二阶段直接选定成交供应商的参考
  4. 了解不同形式：区分封闭式和开放式框架协议的特点，制定相应参与策略
  5. 注重长期合作：框架协议采购注重长期合作关系，供应商应重视履约质量和售后服务

供应商行动建议：建议供应商认真研究《政府采购框架协议采购方式管理暂行办法》，了解框架协议采购的规则和流程，提前准备相关资质和材料，积极参与框架协议采购项目，拓展政府采购市场份额。

总之，《政府采购框架协议采购方式管理暂行办法》的出台，为规范多频次、小额度采购活动提供了明确的法律依据，对提高政府采购效率和效益具有重要意义。供应商应深入研究政策内容，把握采购趋势，优化参与策略，以适应政府采购制度改革的新要求。
